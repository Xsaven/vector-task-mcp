# Workflow

Search:

1. Start with the task-specific query.
2. Add one probe for implementation vocabulary.
3. Add one probe for failure/debugging vocabulary when risk is elevated.

Store:

1. Search for similar memories first.
2. Store concise, reusable knowledge with category and specific tags.
3. Prefer summaries with file/module names and decisions, not raw output.

Cookbook:

Use cookbook for known gates and prescribed workflows. Do not recursively pull cookbook content from cookbook content.
