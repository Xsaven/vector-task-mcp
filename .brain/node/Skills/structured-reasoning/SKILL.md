# Structured Reasoning

Use this skill when the task is ambiguous, high-risk, multi-step, or needs careful tradeoff analysis.

## Flow

1. Analysis: identify requirements, constraints, unknowns, and dependencies.
2. Inference: generate plausible approaches and connect them to evidence.
3. Evaluation: reject weak or contradictory approaches.
4. Decision: state the chosen path, residual risk, and verification needed.

Keep reasoning concise in user-facing output. Use the structure to improve work, not to dump private deliberation.
